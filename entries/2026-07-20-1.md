---
title: "Smoother event duplication, steadier in-person payments, and working link previews"
date: 2026-07-20
---

[improved]

- The billing page's Free Guests card now shows the date your free guest allowance resets, so you don't have to cross-reference the credit cycle date shown elsewhere on the page.

[fixed]

- Fixed an issue where duplicating an event could create broken booking and invite links and, instead of landing on the new event's availability page, left you on the dashboard.
- Fixed an issue where the bookings list could time out and fail to load for events with a large number of bookings.
- Fixed an issue where an in-person card payment could fail with an error if the card reader didn't respond right away, instead of retrying automatically.
- Fixed an issue where check-in scanner data could fail to sync due to upload errors.
- Fixed an issue where adding a new location to an event from the edit page didn't appear until the page was refreshed.
- Fixed an issue where signed-in users following an organisation invite link were not added to the organisation.
- Fixed an issue where sharing an organisation's page on Facebook, LinkedIn, or WhatsApp could show a broken or missing preview thumbnail.
