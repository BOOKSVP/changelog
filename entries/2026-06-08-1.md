---
title: "Smarter check-ins, reliable booking retries, and portal invite fixes"
date: 2026-06-08
---

[fixed]

- Fixed an issue where guests who abandoned a paid checkout could not rebook if the "prevent duplicate bookings" setting was on, even though their previous checkout was never completed.
- Fixed an issue where One Pass scans were recorded as valid but guests were not marked as checked in.
- Fixed an issue where organisation share invite links did not grant membership when signing up via Google or a one-time passcode, leaving new users without access to the invited organisation.
- Fixed an issue where the option to add or edit guests remained visible on the booking confirmation screen even when the event's guest-editing setting was turned off.
- Fixed an issue where a white dot appeared floating below the QR code on the ticket page for single-guest bookings.
- Fixed an issue where entering an extremely large capacity value caused a server error instead of a validation message.
- Fixed an issue where some icons appeared as broken images in the app following a logo update.

[improved]

- The booking notification email setting now displays a note confirming that notifications are sent on both booking confirmation and cancellation.
- Updated logo files are now available to download on the brand assets page.
- The free trial period for new Pro and Expert plan signups is now 7 days.
