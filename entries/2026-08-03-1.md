---
title: "Steadier portals, clearer tax options, and smoother event creation"
date: 2026-08-03
---

[new]

- Portals now receive an email when a CSV guest-list import finishes.
- Added an option to show a ticket's tax category (e.g. "+ VAT") on the booking page without revealing the calculated amount until checkout.
- Added a Help Centre link to the public site footer for quick access to support articles.

[improved]

- Polished the portal home page, guest-list guidance, and Help section, and portals now show their connected organisation with team invitations for access.
- Updated the emails that guide portal partners on creating invites and sharing links to match the redesigned portal experience.
- Renamed the promo code usage limit to "Booking limit" so it's clear the limit applies once per booking, not per ticket.

[fixed]

- Fixed an issue where creating an event could fail to save if a ticket's "hide tax amount" option was left unchecked.
- Fixed an issue where a portal's allocation usage, invited, and confirmed guest counts could disagree with each other.
- Fixed an issue where connecting a portal to an existing organisation could create a duplicate organisation instead of using the one you selected.
- Fixed an issue where adding a guest to an existing booking could inflate the guest count by more than one.
- Fixed an issue where portal group pages could time out and fail to load.
- Fixed an issue where importing guests via CSV in the new portal experience could fail.
- Fixed an issue where a portal invite allocation with no set limit could crash the invite screen.
- Fixed an issue where portals could still send invites or share booking links for events and collections that had already ended.
- Fixed an issue where some portal links showed an error page instead of the invitation screen.
- Fixed an issue where a portal's allocation dates and times didn't match what guests see on the public booking page.
- Fixed an issue where searching for a contact while adding a guest to a booking could fail to load results.
- Fixed an issue where custom invite, booking, and portal email text could show up in inconsistent, oversized font sizes on mobile Gmail and Outlook.com.
- Fixed an issue where links in invitation emails could override the surrounding text styling in Apple Mail.
