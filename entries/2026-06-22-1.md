---
title: "Printable tickets, a redesigned reminder email, and fixes for sold-out slots"
date: 2026-06-22
---

[new]

- Guests can now print their tickets or save them as a PDF — a print button appears on the ticket page on desktop, and events using scannable tickets will automatically attach a PDF of all guest tickets to the booking confirmation email.
- The booking reminder email has been redesigned: it now supports its own banner image (uploaded separately from the confirmation banner), displays personalised text before the booking details, and includes a one-click cancel link for upcoming cancellable bookings.
- Expert plan organisations can now enable codeREADr directly from the Scanners page, without needing to contact support.

[improved]

- A copy invite link button now appears in the invite details panel, so you can share an invite link without navigating away.
- Members signing in with ONE PASS no longer need to re-verify on each visit — their session now stays active for a month.

[fixed]

- Fixed an issue where sold-out time slots continued to appear as bookable during high-traffic ticket releases, which could allow overbooking.
- Fixed an issue where location names containing special characters caused Apple Wallet and Google Wallet pass generation to fail.
- Fixed an issue where the custom confirmation text in emails appeared wider than the booking details on mobile screens.
- Fixed an issue where creating a contact list with a duplicate name while importing contacts caused a server error.
- Fixed an issue where opening the availability editor for certain events caused a server error.
