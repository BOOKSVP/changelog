title: "Invitations safe from email link scanners, cleaner booking exports, and collection cards made for phones"
date: 2026-11-02
summary: "A decline link asks the guest to confirm, unpaid rows in the Bookings CSV show zero, and collection cards read more clearly on a phone."
---

[improved]

- **Collection cards read better on a phone.** Event cards on a public collection page wrap their titles neatly on a narrow screen.

[fixed]

- **A decline link asks the guest first.** A workplace email tool, such as Microsoft Safe Links, no longer declines an invitation by opening the link before the guest does. Declining always asks the guest to confirm.
- **An unpaid booking shows 0 in the CSV.** The Bookings CSV no longer shows amounts for a checkout that was never paid. Every money column on an unpaid row is 0, so the totals add up.
