---
title: "Portal access requests, clearer reminders, and drafts that save on Windows"
date: 2026-09-14
---

[new]

- Locked-out portal visitors can request access from the connected organisation: the owner gets an email to allow access and send a team invite that unlocks the portal.

![Locked portal screen with Request access button for Chase Gallery](assets/2026-09-14-portal-access/1_locked.png)

![Portal access request accept screen for Chase Gallery](assets/2026-09-14-portal-access/5_accept.png)

- The invite composer has a "Send me a test" button, so you can preview the exact invite email before sending it to guests.
- Organisations can turn Stripe buyer payment receipts on or off from Settings → Payouts (on by default).
- "Artist" is now a team type when creating an organisation or connecting a portal partner.

[improved]

- Custom reminder emails show the event time zone and clearer delivery status on each booking, and edited reminders can fire again at their new time.
- Collection cards now show Fully Booked or Waitlist when an event is unavailable, and sold-out detection matches the event page and API (including ticket-quantity sell-outs).
- Pro and Expert plans no longer cap how many event-level team members you can invite.
- Check-in staff can add walk-ins and confirm invites at the door without needing a fuller admin role.
- Banner images can be free-cropped and display at full height in previews.
- You can add extras (such as programmes) to an existing booking from the booking page.
- Cancel Event is back in the new admin event menu.
- Booking pages with a Facebook Pixel now fire PageView after consent, so remarketing can reach visitors who browsed but did not book.
- Invites can include a mobile number, ready for WhatsApp or SMS outreach when messaging is configured.

[fixed]

- Fixed Windows users being unable to save drafts or other multipart admin forms ("Draft won't save" / Forbidden), including the create-event wizard, invite composer, and design uploads.
- Fixed bookings that reported as deleted but stayed live and kept holding seats when stored data failed validation.
- Fixed portal phone numbers entered with a country code but without a leading + being rejected.
- Fixed duplicated portals inheriting the original partner's connection and showing as Inactive, and fixed signed-out portal Continue landing on a broken layout.
- Fixed credit-pack purchase modals failing to open for some organisations, and fixed several admin navigation issues on billing, editors, designs, and portals.
- Fixed concurrent check-ins at the door erroring instead of showing that a guest was already checked in.
