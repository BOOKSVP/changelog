---
title: "Cancel an event properly, WhatsApp invites with pictures, and one person across several emails"
date: 2026-10-05
---

[new]

- Cancel an event from the new admin in three steps: choose whether to email guests, write the message, and confirm. Cancelled events read as cancelled everywhere — booking pages, tickets (QR greyed out), ONE Pass, portals, and the public feed. Invited guests with an email get the cancellation too, not only bookers, and scheduled reminders stop.
- WhatsApp invitations now open with the event's picture — the same Social Sharing card used for link previews — so guests see the show before they tap through.
- Several email addresses can belong to one person: merge them on a contact card so guest history reads as one profile, and guests can add emails under Your emails on ONE Pass so their pass opens bookings for every linked address.
- Creating an event offers a Public Event starting point, and new organisations set a real venue (or Online) during onboarding so wallet passes work from the first event.
- Guest lists gain a Booking links filter, and the Guests count on a link panel opens that filtered list — so you can see who booked through a specific link without downloading a CSV.
- An optional Created column on portal, All Guests, event and collection guest lists sorts newest first when you turn it on.

[improved]

- Removing an event from a portal keeps that partner's guests, invitations and booking links on the portal. You choose whether what's already sent can still be used, or force-close the allocation.
- Google Wallet "Add to Wallet" shows a minting page while the pass generates, instead of a blank tab.
- Descriptive copy across the new admin is warmer and more consistent — tooltips, empty states, hints and confirmations rewritten as plain whole sentences.

[fixed]

- Fixed form pop-ups vanishing with no message when something went wrong, leaving organisers with a blank screen and lost typing.
- Fixed Apple Wallet links sending guests into organiser onboarding when they happened to be signed in with an unfinished account.
- Fixed portal "Allow access" email links sending partner owners to create-your-first-event instead of the accept page.
- Fixed removing the last extra or promo code on an event failing to save, so the row came back after save.
- Fixed contact autocomplete and large-space invite and guest-list pages timing out on the heaviest organisations.
