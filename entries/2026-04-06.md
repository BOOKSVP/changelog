---
title: "Entry Times for Tickets, Faster Event Pages & Sales Report Fixes"
date: 2026-04-06
---

[new]

- **Entry Times for Tickets** — You can now set a specific entry time on individual ticket types. Guests will see their allocated entry time on their booking confirmation. Ideal for fairs and events with staggered arrival slots.

- **Custom Fields Editing** — Admins can now edit, rename, reorder and delete custom fields directly from the event custom fields page. Fields can be dragged into the order you want them to appear on booking forms.

[improved]

- **Event pages load faster** — Reduced the number of database queries when displaying events with multiple ticket types, resulting in noticeably faster load times for complex events.

- **Booking link conflicts resolved** — Fixed an edge case where events and collections sharing a URL slug could send guests to the wrong place. Links now resolve correctly in all cases.

- **Register Interest — clearer messaging** — When a "Register Interest" event has already passed, guests now see a message that reflects this rather than the standard interest form copy.

[fixed]

- **Sales report fee totals corrected** — The sales report was over-counting the ARTSVP fee for bookings with multiple ticket types (e.g. showing 10% instead of 5%). This has been corrected and reports now reflect accurate fee amounts.

- **Sales report product grouping fixed** — Products with the same name were being merged into a single line in the sales report. Each product line item now appears separately as expected.

- **Ticket entry time display fixed** — Entry times were displaying as a date range instead of a single time. This is now shown correctly.
