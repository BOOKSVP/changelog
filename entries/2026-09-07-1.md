---
title: "A new scanner experience, sharper ONE Pass insights, and fewer ticket headaches"
date: 2026-09-07
---

[new]

- A new full-screen camera scanner makes check-in faster: point your phone or tablet at a ticket to scan it, with live entry counts and clear on-screen feedback for every guest.
- Sold-out events on collection pages now show a "Sold Out" badge, so visitors don't need to click through to see availability.
- Apple Wallet passes can now use custom text and label colours in the ticket designer, instead of always matching the background.

[improved]

- The ONE Pass dashboard has been rebuilt with more accurate activation and usage figures, and now loads noticeably faster.
- Replaced the support chat widget with a faster, account-linked chat experience, and fixed it covering navigation buttons on mobile.
- Refreshed the explainer and welcome screen shown when switching to the new admin experience, with clearer feature highlights.
- Strengthened security safeguards around live booking, check-in, and notification updates.
- The public events API is faster for organisations with a long event history and now returns large event lists in pages instead of timing out.

[fixed]

- Fixed an issue where organisations on a paid plan were still being charged the free plan's booking fee.
- Fixed Apple Pay not appearing as a payment option on some ticket pages.
- Fixed an issue where changing an event's time zone, or daylight saving time, could cause tickets and bookings to show the wrong time; changing a time zone now also asks whether existing bookings should move with it.
- Fixed an issue where clicking "Manage Booking" in a confirmation email could send guests to a sign-in page instead of their booking.
- Fixed CSV contact imports failing when a contact had more than five tags, and fixed bulk tagging discarding a contact's existing tags.
- Fixed multi-day event tickets showing the wrong end time on shorter days.
- Fixed an issue where increasing an event's capacity didn't update its availability, leaving it marked as sold out.
- Fixed the ticket designer showing your organisation's name on a wallet pass even when the logo text field was left blank.
- Fixed an error when adding a guest with a slightly malformed email address, which now shows a clear message instead of a broken screen.
- Fixed the guest invites list failing to load on large spaces.
- Fixed several issues on partner portals: archiving a portal group failing silently, a dropdown menu getting cut off in the portal editor, and missing allocation details for past-season portals.
- Fixed an issue where switching between the new and classic admin views could break buttons and toast notifications until the page was reloaded.
- Fixed ticket quantity +/- controls not working on some booking and guest list pages.
