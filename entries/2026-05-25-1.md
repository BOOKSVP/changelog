---
title: "Scheduled location reveals, portal booking exports, and cleaner booking flows"
date: 2026-05-25
---

[new]

- Organisers can now set a specific date and time at which a private event location becomes visible to guests, rather than always revealing it at booking confirmation.
- Portal administrators can now download a CSV export of all portal bookings, including guest names, email addresses, event details, and attendance status.

[improved]

- The custom form fields panel on the event edit page now updates live without scrolling back to the top, and fields are grouped by type to match the order they appear on the booking form.
- Contact search is now significantly faster for organisations with large guest lists and no longer times out.
- The guest list CSV now includes additional booking metadata.
- Event date and time are now shown when adding events to a scanner, making it easy to distinguish events that share the same name.
- You can now copy a guest's booking confirmation link directly from the booking details panel.

[fixed]

- Fixed an issue where credit pack purchases were charged in the wrong currency or at an incorrect amount for organisations billed outside of USD.
- Fixed an issue where email subjects containing special characters like & arrived with HTML entity codes (such as &amp;) instead of the intended text.
- Fixed an issue where bookings for events with multiple time windows on the same day failed with an end-time validation error.
- Fixed an issue where Google Calendar "Add to Calendar" links on Android opened to the app's home screen instead of the event creation form.
- Fixed an issue where the portal booking export failed when guest records contained blank email addresses.
- Fixed an issue where booking managers received "Access Denied" when navigating to Slot Analysis.
- Fixed an issue where the booking form's action button label did not update when ticket quantities were changed on the page.
